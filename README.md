# facecount-ocx
Detect several faces in one picture and report how many were found — callable from C#, VB.Net, VB, C++, Delphi, Vfp or MS Access.
Overview

<b>Install</b>

Grab the ActiveX runtime installer from the vendor download page.

<b>What it does</b>

1. Reads BMP, JPEG, PNG and TIFF files.

2. Turns a face count into footfall or attendance figures for shops, airports and schools.

3. Recognises frontal, profile, and tilted profiles on either side.

4. Applies histogram equalisation when lighting is flat.

5. Writes out JPEG or PNG copies with boxes drawn over each face.

6. Returns the coordinates of every detected face.

7. Exposes the neighbour threshold used when merging candidate rectangles.

8. Takes a minimum object size, dropping anything smaller.

9. Takes a maximum object size, dropping anything larger.

10. Ships sample projects for VB.Net 2019, VB.Net 2010, C# 2019, C# 2010, Visual Basic 6, Visual C, Visual Foxpro and Delphi.

11. Works from any host that can load ActiveX controls.

12. The OCX can be redistributed royalty free.
